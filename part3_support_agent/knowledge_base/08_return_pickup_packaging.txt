Products approved for return should be securely packed before the scheduled pickup to help prevent damage during transportation.

Customers should include the original product, accessories, manuals, tags, and packaging when these items are required by the applicable return policy.

During pickup, the return may be checked for basic eligibility conditions such as the correct product, required accessories, and visible physical condition.

A return pickup may be rejected or delayed if required components are missing, the product does not match the return request, or the item is not properly prepared for pickup.
