7. LANGGRAPH WORKFLOW
---------------------

The support agent routes requests between:

- Policy RAG
- Return-risk prediction
- Product-image classification
- Conversation/order context
- Input safety guardrails

The final response passes through a deterministic MOCK_LLM layer so the project can be evaluated without external API keys.
